# NEXORA AI — Modern AI Consulting Website

A responsive four-page static website in a dark blue / white / electric blue theme.

## Pages
- Home — hero, value proposition, services, CTA, stats
- Services — AI Consulting, Generative AI, AI Automation, Recruitment AI, Data Analytics, AI Enablement
- About — positioning, delivery approach, principles
- Contact — responsive inquiry form with demo success state

## Run locally
Open `index.html` in a browser, or use a lightweight local server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Production
Connect the contact form in `contact.html` to your backend/CRM endpoint and replace the sample company details.
